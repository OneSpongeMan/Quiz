# Quiz

Веб-платформа для создания, прохождения и администрирования викторин. Backend реализован на ASP.NET Core и предоставляет REST API для клиентского приложения. Система поддерживает ролевую модель доступа, учёт результатов прохождения, ограничение по времени и формирование отчётности по изменениям контента викторин.

## Назначение

Приложение предназначено для организаций и авторов, которым нужен инструмент для подготовки тестов с вопросами и вариантами ответов, проведения викторин с фиксацией результата и последующего анализа активности пользователей. Администратор управляет пользователями, ролями и полным набором викторин. Пользователь может создавать собственные викторины, проходить доступные тесты и просматривать историю своих результатов.

## Архитектура

Решение построено по многослойной схеме и разделено на четыре проекта:

- **Quiz.API** — HTTP-слой: контроллеры, DTO, маппинг, конфигурация приложения и начальное наполнение базы данных.
- **Quiz.BLL** — бизнес-логика: сервисы для работы с викторинами, вопросами, ответами, результатами, пользователями и ролями; генерация PDF-сертификатов.
- **Quiz.DAL.EF** — доступ к данным через Entity Framework Core: контекст базы данных, конфигурации сущностей, загрузчики, миграции.
- **Quiz.Shared** — доменные модели и контракты интерфейсов между слоями.

Зависимости между слоями направлены от API к BLL и DAL через абстракции в Shared. Для преобразования моделей в DTO используется AutoMapper.

## Основные возможности

**Управление викторинами.** Создание, редактирование и удаление викторин с названием, описанием, тегами, ограничением по времени и привязкой к автору. Поиск по имени, тегам и автору, получение списка пройденных пользователем викторин.

**Вопросы и ответы.** CRUD для вопросов внутри викторины, включая текст, тип ответа и изображение. CRUD для вариантов ответов с балльной оценкой; корректные ответы определяются ненулевым значением `Score`.

**Прохождение викторины.** Старт и завершение попытки с сохранением времени начала и окончания. Принудительное завершение при истечении лимита времени. Подсчёт набранных баллов по выбранным ответам.

**Пользователи и роли.** ASP.NET Identity с ролями Admin и User. Отдельные маршруты API для администратора и обычного пользователя. У пользователя есть проверка прав автора при изменении контента.

**Результаты.** Хранение попыток прохождения с количеством баллов и правильных ответов. Получение результатов по викторине и по текущему пользователю.

**PDF-сертификат.** Генерация документа с результатами прохождения викторины: имя пользователя, дата, длительность, процент набранных баллов.

## Требования

- .NET 8 SDK
- PostgreSQL
- Клиентское приложение (отдельный репозиторий или каталог), если требуется полный UI

## Настройка и запуск

1. Создайте базу данных PostgreSQL и укажите строку подключения к ней в `Quiz.API/appsettings.json`:

```json
"ConnectionStrings": {
  "DefaultConnections": "Host=localhost;Port=5432;Database=QuizDB;Username=postgres;Password=<password>"
}
```

2. Запустите API:

```bash

cd Quiz.API

dotnet run

```
